# AI 模型设置中心开发流程

## 功能定位

AI 模型设置中心负责统一配置文本、图片、视频、音频和口型同步相关模型。它让用户可以在页面中切换 provider、base URL、API key、模型名、超时和 fallback 策略，而不是每次都修改环境变量。

## 用户操作流程

1. 用户进入模型设置页。
2. 页面读取当前模型配置。
3. 用户按分组切换：文本、图片、视频、音频等。
4. 修改 provider、模型名、接口地址或密钥。
5. 点击保存。
6. 后端写入 `model_settings`。
7. 后端把生效配置同步到当前 Node.js 进程的 `process.env`。
8. 后续生成任务立即使用新配置。

## 前端开发流程

相关页面：

- `src/views/AISettings.vue`

相关 API：

- `getModelSettings()`
- `updateModelSettings(settings)`

页面核心状态：

- `groups`：配置分组。
- `fields`：配置字段。
- `effective`：当前生效值。
- `draft`：页面编辑值。
- `changedCount`：变更数量。
- `saving`：保存中状态。

密钥字段不会明文展示。保存时，如果 secret 字段为空，后端不会覆盖旧密钥。

## 后端开发流程

后端入口：

- `server/index.mjs`

相关服务：

- `server/services/ai/config.mjs`
- `server/services/frame.mjs`
- `server/services/video.mjs`
- `server/services/audio.mjs`
- `server/services/lip-sync.mjs`

接口：

```text
GET /api/model-settings
PUT /api/model-settings
```

读取流程：

```text
GET /api/model-settings
  -> authenticate
  -> buildModelSettingsPayload()
  -> 读取 MODEL_SETTING_FIELDS
  -> 合并 process.env 和 model_settings 表
  -> secret 字段只返回是否已配置
  -> 返回分组、字段和生效值
```

保存流程：

```text
PUT /api/model-settings
  -> authenticate
  -> 校验 settings 数组
  -> 过滤未知字段
  -> 校验 number / boolean / secret
  -> secret 为空不覆盖
  -> upsert model_settings
  -> process.env[key] = value
  -> 返回最新配置
```

## 主要配置分组

文本模型：

- `AI_PROVIDER`
- `AI_BASE_URL`
- `AI_API_KEY`
- `AI_MODEL`
- `AI_MODEL_OUTLINE`
- `AI_MODEL_SCRIPT`
- `AI_MODEL_STORYBOARD`
- `AI_MODEL_CHARACTER`
- `AI_TIMEOUT_MS`
- `AI_FALLBACK_TO_MOCK`

图片模型：

- `FRAME_PROVIDER`
- `FRAME_BASE_URL`
- `FRAME_API_KEY`
- `FRAME_MODEL`
- `FRAME_WATERMARK_ENABLED`
- `FRAME_IMAGE_RATIO`
- `FRAME_FALLBACK_MODELS`
- `FRAME_FALLBACK_TO_MOCK`

当前火山方舟图片生成配置示例：

- Provider：`volcengine`
- Base URL：`https://ark.cn-beijing.volces.com/api/v3`
- Model：`doubao-seedream-4-5-251128`
- Size：`2K`
- Ratio：`16:9`

注意：模型设置保存到 `model_settings` 后，API 和 Worker 都要重新加载配置；只启动 API 而没有启动 Worker，生成任务会停留在 `queued`。

音频模型：

## 异常处理

- 未知配置项：忽略或拒绝。
- number 字段不是正整数：返回错误。
- boolean 字段统一转成 true/false 字符串。
- secret 字段为空：不覆盖旧密钥。
- 保存后立即更新 `process.env`，避免必须重启服务。

## 上台讲解话术

```text
模型设置中心解决的是模型接入和演示切换问题。
文本、图片、视频和音频模型都有不同 provider 和密钥，如果全部写死在代码里，演示和部署都不方便。
所以我做了 model_settings 表，页面保存后后端会同步到当前 Node 进程的环境变量。
这样后续生成总纲、静帧、视频或音频时，就会直接使用新的模型配置。
```
