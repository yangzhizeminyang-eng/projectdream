# 任务中心与后台生成任务模块开发流程

## 功能定位

任务中心负责展示图片、视频、口型同步和导出等长耗时任务的运行状态。它让用户在生成任务提交后可以离开页面，稍后统一查看排队、执行、成功、失败、取消和重试状态。

## 用户操作流程

1. 用户在静帧、视频、口型同步或导出页面提交任务。
2. 后端创建任务记录。
3. 页面可以轮询单个任务。
4. 用户也可以进入任务中心查看项目下所有任务。
5. 对失败任务，用户可以点击重试。
6. 对可取消任务，用户可以点击取消。
7. 任务完成后，结果回写到素材表或导出表。

## 后端开发流程

后端入口：

- `server/index.mjs`

核心表：

- `generation_jobs`
- `task_runtime_states`

核心函数：

- `createGenerationJob()`
- `queueGenerationJob()`
- `updateGenerationJob()`
- `processGenerationJob()`
- `recoverGenerationJobs()`
- `resumeQueuedGenerationJobs()`
- `buildProjectTasks()`
- `decorateProjectTaskItem()`

接口：

```text
GET  /api/generation-jobs/:jobId
GET  /api/projects/:projectId/tasks
POST /api/project-tasks/:taskKey/retry
POST /api/project-tasks/:taskKey/cancel
POST /api/generation-jobs/:jobId/retry
POST /api/generation-jobs/:jobId/cancel
```

后台任务流程：

```text
业务页面提交生成
  -> createGenerationJob(status='queued')
  -> queueGenerationJob(jobId)
  -> processGenerationJob()
  -> status queued -> running
  -> 按 job_type 分派：
       frame_image
       character_image
       video_image
       lip_sync
  -> 成功写 result_json
  -> 失败写 error_text
  -> 前端轮询展示进度
```

任务中心汇总流程：

```text
GET /api/projects/:projectId/tasks
  -> authenticate
  -> 校验项目归属
  -> 查询图片、视频、音频、导出等素材
  -> 查询 task_runtime_states / generation_jobs
  -> 合并成统一任务项
  -> 返回 summary + items
```

## 任务类型

常见任务：

- `frame_image`：分镜静帧。
- `character_image`：角色定妆图。
- `video_image`：图生视频。
- `lip_sync`：口型同步。
- `export`：成片导出。

任务状态：

- `queued`
- `running`
- `success`
- `failed`
- `canceled`

## 异常处理

- 任务已成功不能重复执行。
- 失败或取消任务可以重试。
- 任务不属于当前用户：拒绝。
- 服务重启后 queued/running 任务会尝试恢复。
- 供应商错误会通过 `sanitizeProviderError()` 处理后展示，避免泄漏敏感信息。
