# 成片编辑与时间线模块开发流程

## 功能定位

成片编辑模块负责把已确认的视频、静帧和音频组织成最终剪辑草稿。它提供视频轨排序、镜头启用/禁用、音频轨开关、音量控制和基础完整性校验。

时间线模块负责计算每个镜头的开始时间、结束时间，以及对白和旁白应该从哪里进入。

## 用户操作流程

1. 用户进入成片编辑页。
2. 页面读取项目、确认视频、静帧兜底素材和确认音频。
3. 后端构建默认时间线草稿。
4. 用户调整视频片段顺序、启用状态和音频轨音量。
5. 用户保存剪辑草稿。
6. 后续导出模块读取这个草稿进行合成。

## 前端开发流程

相关页面：

- `src/views/FinalEdit.vue`

相关 API：

- `getProject(projectId)`
- `getProjectFinalEdit(projectId)`
- `updateProjectFinalEditDraft(projectId, payload)`

页面核心状态：

- `finalEdit`：后端返回的完整成片数据。
- `editableVideoClips`：可编辑视频轨。
- `audioMixState`：音频混音配置。
- `lastSavedSignature`：判断是否有未保存改动。
- `localValidation`：前端本地校验。

用户移动镜头顺序、关闭镜头、调整音量后，前端构造草稿：

```text
videoClips + audioMix
```

并保存到后端。

## 后端开发流程

后端入口：

- `server/index.mjs`

服务：

- `server/services/media-timeline.mjs`
- `server/services/export-validation.mjs`

接口：

```text
GET /api/projects/:projectId/final-edit
PUT /api/projects/:projectId/final-edit-draft
```

读取流程：

```text
GET /api/projects/:projectId/final-edit
  -> authenticate
  -> 校验项目归属
  -> 查询分镜、确认视频、确认图片、确认音频
  -> fetchFinalEditDraft()
  -> normalizeFinalEditDraft()
  -> buildMediaTimeline()
  -> buildFinalEditValidation()
  -> 返回时间线和音频轨
```

保存流程：

```text
PUT /api/projects/:projectId/final-edit-draft
  -> authenticate
  -> 校验项目归属
  -> 接收 videoClips + audioMix
  -> normalizeFinalEditDraft()
  -> upsert final_edit_drafts
  -> 返回最新 FinalEditDTO
```

## 时间线算法

核心文件：

- `server/services/media-timeline.mjs`

关键函数：

- `buildMediaTimeline(clips)`
- `resolveMediaStartSeconds(item, timeline)`
- `hasStoryboardTimelineEntry(item, timeline)`
- `resolveRequiredSpeechDuration(item)`
- `buildLegacySceneAudioOffsets(audioItems, timeline)`
- `buildAtempoFilter(sourceDurationSeconds, targetDurationSeconds)`

时间线计算逻辑：

```text
遍历启用的视频片段
  -> 每条片段取 durationSeconds
  -> 累加 cursor
  -> 得到 startSeconds / endSeconds
  -> 建立 byStoryboardId 和 bySceneId 索引

音频定位
  -> 优先通过 storyboardId 找镜头起点
  -> 加上 startOffsetSeconds
  -> 没有 storyboardId 时兼容旧 scene 级音频
```

## 异常处理

- 没有确认视频时，使用确认静帧作为静态兜底，但导出会根据完整性限制。
- 用户禁用了全部镜头：校验失败。
- 音频轨全部关闭：提示但不一定阻塞。
- 草稿引用已删除分镜：规范化时过滤。
- 音频比镜头长很多：导出阶段使用 `atempo` 做适度变速。

## 上台讲解话术

```text
成片编辑模块把前面生成的素材真正组织成时间线。
每个确认视频或静帧会成为一个视频片段，系统根据时长累加出 startSeconds 和 endSeconds。
音频不是简单从头播放，而是优先绑定到分镜，再根据这条时间线找到正确起点。
用户调整顺序和开关后，草稿会保存到 final_edit_drafts，导出时就按这份草稿合成。
```
