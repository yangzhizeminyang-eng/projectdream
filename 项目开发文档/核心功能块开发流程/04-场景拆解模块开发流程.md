# 场景拆解模块开发流程

## 功能定位

场景拆解模块负责把故事总纲中的场景草案落成正式场景。它把一个抽象故事拆成多个可执行片段，每个场景都有标题、地点、时间、摘要、氛围和预估时长。

## 用户操作流程

1. 用户进入场景拆解页。
2. 页面读取项目、最新总纲和已有场景。
3. 用户点击生成场景。
4. 后端基于总纲中的场景列表写入 `script_scenes`。
5. 用户可以切换场景、修改标题、摘要、地点、时间和氛围。
6. 保存后，后续单场剧本模块会读取这些场景。

## 前端开发流程

相关页面：

- `src/views/Scenes.vue`

相关 API：

- `getProject(projectId)`
- `getLatestOutline(projectId)`
- `listScenes(projectId)`
- `generateScenes(projectId)`
- `updateScene(sceneId, payload)`

页面核心状态：

- 当前项目
- 当前总纲
- 场景列表
- 当前选中场景
- 表单草稿
- 是否有未保存改动
- 重新生成确认弹窗

场景页支持人工修正。用户切换场景时，如果当前表单有未保存内容，会弹出确认，避免编辑内容丢失。

## 后端开发流程

后端入口：

- `server/index.mjs`

接口：

```text
GET  /api/projects/:projectId/scenes
POST /api/projects/:projectId/scenes/generate
GET  /api/scenes/:sceneId
PUT  /api/scenes/:sceneId
```

生成正式场景流程：

```text
POST /api/projects/:projectId/scenes/generate
  -> authenticate
  -> 校验项目归属
  -> 查询最新 story_outlines
  -> 从总纲 raw_json / scenes 字段读取场景列表
  -> 规范化 scene_no、title、summary、location、time_of_day
  -> 写入 script_scenes
  -> 更新项目 status
  -> 返回场景列表
```

更新场景流程：

```text
PUT /api/scenes/:sceneId
  -> authenticate
  -> 校验场景归属当前用户
  -> 只更新允许字段
  -> 过滤空值和非法 estimatedDuration
  -> 返回 SceneDTO
```

## 数据表说明

核心表：

- `script_scenes`

关键字段：

- `project_id`：所属项目。
- `outline_id`：来源总纲。
- `scene_no`：场景编号。
- `title`：场景标题。
- `summary`：场景摘要。
- `content`：后续单场剧本文本。
- `mood`：氛围。
- `location`：地点。
- `time_of_day`：时间段。
- `estimated_duration`：预估时长。
- `sort_order`：排序。
- `status`：场景状态。

## 异常处理

- 没有总纲时不能生成正式场景。
- 总纲里没有可用场景列表时返回错误。
- 场景不属于当前用户时拒绝访问。
- 场景预估时长小于等于 0 时忽略非法值。
- 重新生成场景会影响后续剧本和分镜，所以前端需要确认。

## 上台讲解话术

```text
场景拆解模块把总纲从“故事大纲”变成“可以执行的生产单元”。
每个场景都有编号、标题、地点、时间和摘要，并且保存到 script_scenes 表。
后续单场剧本和分镜都不是直接读总纲，而是先读这些正式场景。
这样系统可以逐场推进，也方便用户只修改某一场，不影响整个项目。
```
