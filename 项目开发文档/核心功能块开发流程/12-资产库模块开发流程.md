# 资产库模块开发流程

## 功能定位

资产库模块负责统一展示项目中的角色、图片、视频、音频和导出素材。它不是生成入口，而是结果管理入口，用来查看素材来源、状态、数量和最近更新时间。

## 用户操作流程

1. 用户进入资产库。
2. 页面读取当前项目和全部资产汇总。
3. 用户按素材类型、状态或关键字筛选。
4. 用户查看某个素材的来源和确认状态。
5. 用户可以跳转回对应生产模块继续处理。

## 前端开发流程

相关页面：

- `src/views/AssetLibrary.vue`

相关 API：

- `getProject(projectId)`
- `getProjectAssets(projectId)`

页面核心状态：

- 当前项目。
- 资产 summary。
- 资产 items。
- 类型筛选。
- 状态筛选。
- 搜索关键词。
- 排序方式。
- 网格/列表视图。

资产库会通过 `getWorkspaceContext()` 补当前项目 ID，并通过 `setWorkspaceContext()` 保持侧边栏跳转上下文。

## 后端开发流程

后端入口：

- `server/index.mjs`

接口：

```text
GET /api/projects/:projectId/assets
```

汇总流程：

```text
GET /api/projects/:projectId/assets
  -> authenticate
  -> 校验项目归属
  -> 查询 characters
  -> 查询 image_assets
  -> 查询 video_assets
  -> 查询 audio_assets
  -> 查询 export_records
  -> 统一转换为 asset item
  -> 统计 summary
  -> 返回 ProjectAssetsDTO
```

## 数据来源

资产库主要读取：

- `characters`
- `character_images`
- `image_assets`
- `video_assets`
- `audio_assets`
- `export_records`

每条资产都会包含：

- 类型。
- 名称。
- 状态。
- URL。
- 来源对象。
- 创建时间。
- 更新时间或确认时间。

## 状态说明

常见状态：

- `candidate`：候选。
- `confirmed`：已确认。
- `archived`：已归档。
- `completed`：已完成。
- `failed`：失败。

资产库不会强行修改状态，状态由各生产模块产生。例如图片在静帧结果页确认，视频在视频页确认，音频在音频页确认，导出在导出页完成。

## 异常处理

- 项目不存在或不属于当前用户：拒绝。
- 某类资产为空：正常返回空列表。
- 历史素材字段缺失：使用安全占位。
- 媒体 URL 为空：前端展示无预览状态。

## 上台讲解话术

```text
资产库是整个项目的素材总账。
图片、视频、音频、角色定妆图和导出文件不是散落在各个页面里，而是可以统一汇总查看。
后端会从多张素材表里查询数据，再转换成统一资产项。
这样用户可以知道项目里已经生成了多少素材，哪些已确认，哪些还只是候选。
```
