# 项目管理与项目总览模块开发流程

## 功能定位

项目管理模块是全链路的起点。每个项目对应一条完整创作链路，后续总纲、场景、剧本、角色、分镜、静帧、视频、音频、剪辑和导出都通过 `projectId` 关联。

项目总览页负责展示用户已有项目、项目进度、最新导出成片和关键素材数量。

## 用户操作流程

1. 用户登录后进入项目总览页。
2. 总览页读取当前用户的项目列表。
3. 用户点击“新建项目”。
4. 输入项目名称、题材、目标时长、故事方向、视觉风格和画幅比例。
5. 后端创建 `projects` 记录。
6. 前端跳转到 AI 剧本页，带上 `projectId`。
7. 后续所有工作台页面都通过 URL query 或 `sessionStorage` 获取当前项目上下文。

## 前端开发流程

相关页面：

- `src/views/Dashboard.vue`
- `src/views/NewProject.vue`
- `src/components/TopNav.vue`
- `src/components/SideNav.vue`
- `src/lib/context.ts`
- `src/lib/current-project.ts`

相关 API：

- `listProjects()`
- `getProject(id)`
- `createProject(payload)`

总览页调用 `listProjects()`，展示项目卡片。新建页调用 `createProject()`，成功后跳转：

```text
/workspace/script/ai?projectId=xxx
```

`context.ts` 用 `sessionStorage` 保存最近访问的 `projectId / sceneId / storyboardId`。这样用户从侧边栏直接点击模块时，即使 URL 没带 query，也能补上最近项目上下文。

## 后端开发流程

后端入口：

- `server/index.mjs`

关键接口：

```text
GET  /api/projects
POST /api/projects
GET  /api/projects/:projectId
```

创建项目流程：

```text
前端提交项目表单
  -> 后端 authenticate
  -> 校验 name 是否为空
  -> 写入 projects
  -> 返回 ProjectDTO
```

读取项目列表流程：

```text
GET /api/projects
  -> authenticate
  -> 查询当前 user_id 的所有项目
  -> 关联统计总纲、场景、分镜、确认素材和导出记录
  -> buildProjectProgress()
  -> 返回项目卡片数据
```

## 数据表说明

核心表：

- `projects`

关键字段：

- `id`：项目 ID，后续所有模块的主线。
- `user_id`：项目归属用户。
- `name`：项目名称。
- `category`：题材分类。
- `target_duration`：目标时长。
- `narrative_vision`：故事方向。
- `visual_style`：视觉风格。
- `aspect_ratio`：画幅比例。
- `status`：项目阶段状态。

总览页还会读取：

- `story_outlines`
- `script_scenes`
- `storyboards`
- `image_assets`
- `video_assets`
- `audio_assets`
- `export_records`

## 进度计算逻辑

`buildProjectProgress()` 会按素材完成情况推断项目阶段。

大致逻辑：

```text
已有导出记录 -> 已导出成片
已有确认视频 -> 视频素材已就绪
已有确认静帧 -> 静帧素材制作中
已有分镜 -> 分镜制作中
已有场景 -> 剧本已就绪
已有总纲 -> 总纲已就绪
否则 -> 筹备中
```

这让项目总览不是固定状态，而是从真实数据反推项目进度。

## 异常处理

- 未登录访问项目接口：返回未授权。
- 项目不存在：返回 404。
- 项目不属于当前用户：拒绝访问。
- 新建项目名称为空：返回业务错误。
- 老数据字段缺失或乱码：总览页使用安全占位，避免页面崩掉。

## 上台讲解话术

```text
项目模块相当于整个系统的主线。
用户创建项目以后，后面所有总纲、场景、角色、分镜、素材和导出记录都围绕 projectId 展开。
项目总览不是简单列表，它会根据数据库里真实完成的素材数量计算进度，比如是否已经有总纲、分镜、确认视频和导出记录。
这样用户一进来就能看到每个项目推进到了哪一步。
```
