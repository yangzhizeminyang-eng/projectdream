# 合成导出模块开发流程

## 功能定位

合成导出模块负责把成片编辑草稿中的视频片段、静帧、对白、旁白和字幕合成为最终 MP4。它是项目交付的最后一步。

## 用户操作流程

1. 用户进入导出页。
2. 页面读取导出包预览和历史导出记录。
3. 系统校验素材完整性。
4. 用户选择导出参数，例如格式、分辨率、帧率、是否烧录字幕。
5. 用户点击导出。
6. 后端创建导出记录并启动导出任务。
7. 页面轮询导出历史。
8. 导出完成后，用户可以预览和下载 MP4。

## 后端开发流程

后端入口：

- `server/index.mjs`

服务：

- `server/services/export-validation.mjs`
- `server/services/media-timeline.mjs`
- FFmpeg / FFprobe

接口：

```text
GET  /api/projects/:projectId/export-package
GET  /api/projects/:projectId/exports
POST /api/projects/:projectId/exports
GET  /api/exports/:exportId
GET  /generated/export/:exportId/...
```

导出包预览流程：

```text
GET /api/projects/:projectId/export-package
  -> authenticate
  -> 校验项目归属
  -> 查询分镜、确认视频、确认图片、确认音频
  -> 读取 final_edit_drafts
  -> buildMediaCompleteness()
  -> 返回 ready/missing/canExport
```

创建导出流程：

```text
POST /api/projects/:projectId/exports
  -> authenticate
  -> 校验项目归属
  -> buildExportPackage()
  -> buildProjectFinalEdit()
  -> 校验 canExport
  -> 写入 export_records(status='queued' 或 running)
  -> queueExportJob(exportId)
  -> 返回导出记录
```

后台导出流程：

```text
processExportJob(exportId)
  -> 读取导出记录和项目
  -> 读取成片草稿
  -> 选择真实视频或静态帧兜底
  -> 下载/定位素材文件
  -> 生成字幕 SRT
  -> FFmpeg 转码视频片段
  -> 混合对白、旁白等音频轨
  -> 可选烧录字幕
  -> 输出 MP4 到 .codex-runtime/exports
  -> 更新 export_records completed/failed
```

## 导出完整性校验

核心文件：

- `server/services/export-validation.mjs`

校验规则：

- 没有分镜，不能导出。
- 场景缺分镜，不能导出。
- 分镜缺确认视频，通常不能导出。
- 成片草稿中禁用的镜头不会参与严格音频导出。

## 字幕和音频处理

字幕来自实际对白文本，会去掉说话人、表演提示和无声占位。

音频定位依赖 `media-timeline.mjs`：

- 有 `storyboardId` 的音频按分镜起点放置。
- 旧的场景级音频只在兼容模式下顺序排布。
- 过长音频可以用 FFmpeg `atempo` 适度压缩。

## 异常处理

- 素材不完整：阻止导出。
- FFmpeg 不可用：导出失败并记录错误。
- 远程素材下载失败：导出失败。
- 没有可用视频或静帧片段：导出失败。
- 导出任务失败：`export_records.status = failed`，页面展示错误。

## 上台讲解话术

```text
导出模块是最终交付环节。
它不是简单把某个视频地址返回给用户，而是读取成片编辑草稿，把确认视频、静帧、对白、旁白和字幕统一交给 FFmpeg 合成。
导出前会先做完整性校验，避免分镜没视频、场景没分镜这种半成品被导出。
导出完成后会写入 export_records，用户可以在历史记录里反复查看和预览。
```
