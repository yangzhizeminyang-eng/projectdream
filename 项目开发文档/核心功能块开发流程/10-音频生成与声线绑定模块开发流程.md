# 音频生成与声线绑定模块开发流程

## 功能定位

音频模块负责生成对白、旁白等声音素材，并把音频绑定到具体场景、分镜和角色。声线绑定负责为角色推荐和锁定音色，保证同一角色在不同对白中声音一致。

## 用户操作流程

1. 用户进入音频工作台。
2. 页面读取项目、场景、分镜、角色、音频素材、声线库和角色声线配置。
3. 用户选择音轨类型：对白或旁白。
4. 对白需要选择角色和分镜，旁白可以绑定场景或分镜。
5. 系统自动从分镜对白或场景内容中填充文本。
6. 用户选择声线和模型。
7. 点击生成音频。
8. 生成结果进入音频候选列表。
9. 用户确认音频，并可调整分镜绑定和起始偏移。

页面会根据选择自动判断是否能生成：

- 分镜绑定后，音频会按分镜时间线定位。

## 后端开发流程

后端入口：

- `server/index.mjs`

服务：

- `server/services/audio.mjs`
- `server/services/audio-dialogue.mjs`
- `server/services/audio-title.mjs`
- `server/services/voice-profiles.mjs`
- `server/services/media-timeline.mjs`

接口：

```text
GET  /api/projects/:projectId/audio
POST /api/projects/:projectId/audio/generate
POST /api/audio-assets/:audioId/confirm
PUT  /api/audio-assets/:audioId
POST /api/audio-assets/:audioId/archive
GET  /api/voice-profiles
GET  /api/projects/:projectId/voice-cast
GET  /api/characters/:characterId/voice-recommendations
PUT  /api/characters/:characterId/voice-binding
```

音频生成流程：

```text
POST /api/projects/:projectId/audio/generate
  -> authenticate
  -> 校验项目归属
  -> 校验 trackType
  -> 校验 scene/storyboard/character 是否属于当前项目
  -> dialogue 必须绑定角色
  -> 读取角色锁定声线
  -> extractSpokenDialogue()
  -> generateAudioCandidates()
  -> 写入 audio_assets
```

声线推荐流程：

```text
GET /api/characters/:characterId/voice-recommendations
  -> 读取角色年龄、性别、性格和声线描述
  -> inferCharacterVoiceTraits()
  -> recommendVoiceProfiles()
  -> 返回推荐列表
```

音频定位流程：

```text
PUT /api/audio-assets/:audioId
  -> 更新 storyboard_id
  -> 更新 start_offset_seconds
  -> 后续导出时通过 media-timeline 计算真实起点
```

## 音频对齐规则

系统优先按 `storyboardId` 定位音频起点。如果没有分镜绑定，再兼容旧数据按 `sceneId` 排布。

严格导出模式下，没有绑定分镜的旧音频不会混到片头，避免所有声音从时间线零点开始播放。

## 异常处理

- 对白没有角色：阻止生成。
- 真实音频 provider 下没有文本：阻止生成。
- 对白角色未锁定声线：提示先完成声线绑定。
- 声线 profile 不存在：返回错误。
- 音频绑定的分镜不属于当前项目：拒绝。
- 已确认音频归档：禁止归档，避免破坏导出。

## 上台讲解话术

```text
音频模块不只是生成一段声音，而是把声音绑定到角色和分镜。
对白必须知道是谁说的，也必须使用这个角色锁定的声线。
生成后的音频会保存到 audio_assets，并记录 storyboardId 和 startOffsetSeconds。
导出时系统根据成片时间线计算它真正应该从哪里开始播放，避免声音和画面错位。
```
