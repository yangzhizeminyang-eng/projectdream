## 7. 近期重点模块补充记录

### 7.1 音频模块（二期）

#### 本轮目标

- 在音频模块一期闭环基础上，升级为“来源感知”的项目级音频工作台
- 按 `trackType + sceneId + characterId` 管理候选，而不是只按轨道类型粗分
- 跑通“生成候选 -> 分组查看 -> 确认主版本 -> 归档旧候选”闭环

#### 本轮完成

- 后端生成、读取、确认、归档链路已改成 source-aware
- 旧一期 mock 音频 URL 已兼容，历史演示数据不会直接失效
- 前端音频工作台已支持来源分组、筛选、详情区和上下文回跳
- 默认交互已优化：没有角色时不会再默认卡死在对白轨

#### 本轮适合记录的问题

- 问题 1：一期只能按轨道类型管理，分不清具体属于哪个场景、哪个角色
- 解决：统一改成按 `trackType + sceneId + characterId` 分组
- 问题 2：旧 mock URL 与二期格式不一致，升级后容易把历史演示数据弄坏
- 解决：保留新版格式，同时兼容旧版 URL
- 问题 3：无角色项目默认落在对白轨，页面一打开就像不能用
- 解决：无角色时自动切到 `narration`

#### 验证结果

- `npm run type-check` 通过
- `npm run build` 通过
- 项目级音频二期闭环已用真实项目数据跑通过

### 7.2 任务中心模块（二期）

#### 本轮目标

- 从“记录聚合页”升级为“带运行态的项目级任务中心”
- 支持统一查看静帧、视频、音频、导出记录
- 支持 `queued / running / success / failed / canceled` 状态表达
- 支持重试、取消、来源回跳和自动刷新

#### 本轮完成

- 后端补齐运行态聚合字段与运行态存储
- 新增任务重试与任务取消接口
- 前端任务中心支持类型筛选、状态筛选、自动刷新和详情检查
- 来源模块回跳和结果打开链路已整理完成

#### 本轮适合记录的问题

- 问题 1：任务中心一开始只有业务记录，没有运行态
- 解决：新增 `task_runtime_states` 作为运行态层
- 问题 2：没有真实异步系统时，重试 / 取消很难形成可见闭环
- 解决：先用 mock 运行态推进，让页面具备真实状态演进表现
- 问题 3：取消操作如果不校验状态，容易和业务真相冲突
- 解决：只允许 `queued / running` 状态取消

#### 验证结果

- `npm run type-check` 通过
- `npm run build` 通过
- `node --check server/index.mjs` 通过

### 7.4 成片编辑模块（二期）

#### 本轮目标

- 在一期只读预览基础上，补“最小可编辑闭环”
- 支持视频片段顺序调整、启用 / 禁用、音轨开关和草稿保存
- 在导出前把当前成片草稿纳入校验

#### 本轮完成

- 后端新增 `final_edit_drafts`
- `GET /api/projects/:projectId/final-edit` 已补可编辑聚合数据与导出前校验结果
- 新增 `PUT /api/projects/:projectId/final-edit-draft`
- `FinalEdit.vue` 已支持片段排序、开关、音频启用状态、草稿保存与恢复

#### 本轮适合记录的问题

- 问题 1：一期只有聚合展示，没有“编辑结果持久化”
- 解决：新增 `final_edit_drafts`，按项目保存当前成片草稿
- 问题 2：如果导出仍只看项目下全部 confirmed 视频，会忽略当前成片草稿

- 问题 3：时间线修改只保留在前端内存时，刷新页面体验很差
- 解决：补 dirty 判断、保存草稿、恢复草稿和服务端回写

### 7.7 真实 AI 与角色闭环（2026-07-22）

#### 本轮目标

- 把静帧、视频和音频从 Mock 切换到真实模型
- 让角色模块参与 AI 生产，不再只是手工 CRUD
- 把角色定妆图真正接入分镜图生图

#### 本轮完成

- 文本：总纲、剧本、角色和分镜统一走 OpenAI-compatible 结构化输出
- 角色：项目级自动提取、单角色档案补全、定妆候选确认和音色试听
- 图片：`agnes-image-2.1-flash` 文生图与参考图生图
- 视频：`agnes-video-v2.0` 图生视频与异步轮询
- 音频：DashScope `qwen3-tts-flash` / `qwen3-tts-instruct-flash` 对白、旁白和角色试听
- 一致性：分镜新增 `character_id`，分镜提示读取角色档案，静帧生成自动注入性别/年龄/外貌硬约束与最多 3 张同框角色定妆图

#### 复核修正

- 项目级“同步角色”改为只新增并补空字段，避免覆盖人工设定
- 分镜 AI 优先使用角色真名，不再把已有角色退化为“主角/配角”泛称
- 增加结构化解析测试，锁定角色名归一、年龄/性别画像和音色推荐规则
- 角色手动改名增加影响预览和事务同步，覆盖项目简介、最新总纲、场景正文与分镜文本
- 分镜角色名改为通过 `character_id` 读取最新值，并兼容从旧分镜与剧本说话人标签识别历史姓名
- AI 补全档案不再修改角色姓名，同项目重名会在预览和保存阶段被拒绝
- 角色详情增加“检查姓名引用”，可单独修复功能接入前已经出现的历史姓名不一致
- 新增 13 套系统音色方案，按年龄段、声线性别和气质评分推荐，不再让少年、青年与中年角色共用一个青年音色
- 角色详情增加音色推荐、真实试听、确认锁定；音频工作台增加项目级角色音色总表
- 对白生成强制读取已锁定角色音色，角色声音画像变化后自动取消旧锁定，历史音频保留生成快照
- 静帧生成增加角色一致性预检卡；人物镜头无法匹配角色库或缺少明确性别时前后端阻止生成
- 候选静帧保存 `character_snapshot`，记录生成时角色身份、性别、年龄、外貌和参考图；历史画面不被角色后续修改覆盖
- 画外音、系统声和门外声音仅在画面明确点名可见形象时实体化，避免凭空增加人物

#### 验证结果

- 真实角色抽取、单角色补全、角色定妆图、参考图生图和 TTS 均成功
- 角色定妆图与分镜静帧已改为持久化后台作业，服务重启可恢复排队任务；Agnes `503 Service busy` 会保留真实错误并自动尝试备用图片模型。

4. 成片编辑三期：更完整的时间线交互和导出预设

1. 静帧模块
2. 视频模块
3. 音频模块
4. 总纲 / 剧本 / 分镜文本链

- 这几条链路的 UI、表结构和主流程都已经打好了

1. 项目级批量生成缺失静帧 / 视频 / 对白
2. 持久化任务队列与独立 Worker
3. 媒体转存对象存储
4. FFmpeg 合成、混音和字幕烧录
