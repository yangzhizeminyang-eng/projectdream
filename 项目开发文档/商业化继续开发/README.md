- 旧恢复任务状态纠偏：5 条早期自动确认结果已回退为 `candidate`，不会再绕过人工复核进入终剪确认列表；新增人工确认旧远程视频时的 `projectId` 对象存储参数修复。
- 恢复视频人工复核门禁：恢复候选必须保存画面、人物一致性、动作连续性三项检查并给出 `approved` 结论，才允许确认主版本；`rework` 会保留复核人、时间和备注，但不会进入终剪确认列表。
- 恢复技术检查前置门禁：没有完成自动技术检查与三张抽帧证据的候选不能保存 `approved`；任务中心不会将其显示为有效批准，而会提示先完成技术检查。`rework` 留痕仍可保存，不会触发生成或扣费。
- 项目级恢复视频复核清单：任务中心通过 `GET /api/projects/{projectId}/recovery-video-reviews` 聚合恢复任务，待复核优先、返工其次、完整批准最后；每条可直接进入对应视频生成页，不会替代人工复核或自动确认。
- 腾讯云 COS 私有桶适配：支持上传、查询、读取、删除、过期扫描和短时签名 URL；COS 签名图片 URL 会直接传给视频供应商，避免依赖 ToAPI 图片上传中转。
- 项目 12 已完成一条真实受控竖屏终剪：恢复候选 `videoId=193` 经过单条明确确认后生成 `exportId=30`，只使用 1 个源片段，最终 `ffprobe` 为 `1080x1920 / 24fps / H.264 + AAC / MP4 / 5.0s`；自动质量报告通过，但人工三项签核和 AI 标识尚未确认，不能表述为可直接发布。
- 腾讯云 COS 只读预检：`npm run verify:object-storage` 会先检查凭证、Bucket 和区域，再只执行签名 URL 生成与 `HeadObject`；不会写入、删除或迁移媒体。
- 本地对象到 COS 回填：`npm run replicate:local-media-to-cos -- --projects=12 --limit=5` 默认只输出计划；加上 `--apply` 才会上传，且每条上传后会从 COS 读回并计算 SHA-256。工具不会删除本地对象、修改数据库或触发模型。
- COS 精确回填和恢复源图任务快照：`--keys` 只复制完整匹配且处于指定项目范围内的对象，避免按排序误传无关媒体；恢复任务会保存 `imageStorageKey`，Worker 优先生成 COS 短时 HTTPS 签名 URL。
- 受控恢复 Worker 审计快照：`worker:recovery-once` 的 `--dry-run`/`--apply` 报告会记录目标项目恢复队列的前后快照、queued/running 数量、其他活跃任务 ID 和 `onlyTargetWillRun` 判断；该快照只读，不会锁定或修改其他任务。
- 受控恢复 Worker 越界门禁：报告新增 `queueBoundary`，只允许目标 job 状态变化；其他恢复任务新增、消失或状态变化会使 `boundarySafe=false` 并让脚本返回非零退出码。
- 恢复 Worker 失败任务分诊：`npm run triage:recovery-worker-failures -- --projects=12` 只读扫描失败任务和 COS 起始图，区分供应商网络超时、源图阻塞、重试耗尽和未知错误，不重新入队、不启动 Worker、不调用模型。
- 恢复 Worker 单条控制重试：`npm run retry:recovery-once -- --job-id=<id>` 默认只读检查 COS 源图、签名 URL 和失败分类；只有显式 `--apply --confirm=CONFIRM_RECOVERY_SINGLE_RETRY` 才会保留原失败记录并创建一条 `max_attempts=1` 的新 queued 任务，不会启动 Worker 或批量重试。
- `job 257` 已在明确确认后创建控制重试 `job 270` 并由受控 Worker 单条执行成功；生成 `videoAsset=195`，COS 与三张抽帧技术检查通过，但输出仍为 `1920x1088 / 30fps` 横版候选，必须人工复核后进入竖屏终剪。该条成功不代表批量稳定或可以直接发布。
- 最新代码回归：`npm test` 342 项、类型检查、生产构建和服务端语法检查通过；完整依赖审计历史结果仍为 `npm audit` 0 漏洞。

## 当前产品原则

```text
先研究市场
再做原创试验
再验证三集
再验证十集
最后决定是否规模化和 SaaS 化
```

平台规则、AI 标识、版权要求、投稿字段和分账政策必须在发布前按当时有效的官方规则重新核验。文档中的市场方向是实验假设，不是收益承诺。
