## 不直接照搬的部分

- 第三方项目的模型、ComfyUI 节点和供应商调用不直接写入本项目。
- 外部项目的提示词仅作为工作流参考，项目内由现有 Agent、数据库版本和视频 Worker 统一执行。
- “一致性”不等于模型一定生成成功；ProjectDream 只在证据齐全时允许入队，并保留失败/重试状态。
- 色彩规则也不等于模型一定生成成功：项目只把已有视觉风格和场景色彩证据固化为提示词约束，不伪造视觉模型通过结果；最终仍需检查真实候选视频。

## 本次色彩能力的采用边界

参考 `Rylaispirit/cinematic-video-prompt-skill` 的 MIT 开源提示词方法，但没有复制其第三方调用代码或整套词库。项目只落地以下可验证规则：

- 从项目视觉风格、场景资产提示词和镜头提示词提取已有色彩证据，不凭空发明调色板。
- 明确主色、光源色和局部警示色的职责；例如冷蓝用于环境，红色只留在剧情明确的警示灯。
- 固定起始帧到结束帧的白平衡、曝光和饱和度关系，禁止色温跳变、曝光呼吸和全画面单色滤镜。
- 保护肤色、黑色服装、白色/金属材质、眼镜和固定配饰，避免环境光把角色身份资产染成另一套颜色。

## 本项目的统一链路

```text
剧本
  -> 角色 Agent / 场景 Agent / 道具 Agent
  -> 角色基础图、三视图、场景全景、九宫格、道具参考图
  -> 人工确认并锁定版本
  -> 分镜 Agent 输出详细 shot JSON + @资产引用
  -> @引用展开为图片/提示词/版本/音色快照
  -> 视频 Agent 通过门禁后入队
```
